Movie Rating Analysis

About the Project

This is a beginner-level Python project that contains movie names and their ratings.

Requirements

Python 3

How to Run

Install Python.

Open the project folder in VS Code.

Run the following command in the terminal:

python Analysis.py

Example Output

The program contains four movies:

Dangal — 9

3 Idiots — 10

Jawan — 8

Pathaan — 7
